# ServiceTitan Top Bar Fix

A Tampermonkey script that brings back ServiceTitan's old top-bar layout (Global Navigation): the module menu moves from the left sidebar to a horizontal bar under the top header, with hover dropdowns for submenus.

## Install

1. Install the Tampermonkey extension in your browser.
2. Open this link and click **Install**:
   https://raw.githubusercontent.com/CryptoCode14/servicetitan-topbar-fix/main/servicetitan-topbar.user.js
3. Reload ServiceTitan. The sidebar becomes a top bar.

## Controls

- **Alt+T** — turn the top bar on/off (off = stock sidebar, exactly as ServiceTitan ships it).
- **Alt+R** — diagnostics panel (what the script found on the page).

Updates arrive automatically through Tampermonkey when a new version is published here.
